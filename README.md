# مساعد كتب التلوين على أمازون KDP
تطبيق أندرويد (WebView) يضم الدليل الكامل وخطة العمل والحاسبات.
المطور: Khader Abo Salha

## البناء على GitHub
1. أنشئ مستودعاً جديداً وارفع كل محتويات هذا المجلد (مع .github/workflows/build.yml).
2. افتح تبويب Actions ثم Build APK ثم Run workflow (أو يبدأ تلقائياً عند الرفع).
3. بعد النجاح افتح التشغيلة ونزّل الملف KDPAssistant-APK من قسم Artifacts، فك الضغط وثبّت الـ APK.
